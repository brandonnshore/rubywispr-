# RubyWhisper

RubyWhisper is Ruby Advisory's private macOS dictation workspace.

The macOS app source in `apps/macos` is derived from FreeFlow under the MIT
license. Preserve the upstream FreeFlow notice in `apps/macos/LICENSE` and the
distribution notice in `apps/macos/Resources/ThirdPartyNotices.md` before any
public beta artifact.

Upstream FreeFlow website, demo, and release assets are intentionally excluded
from this workspace as RubyWhisper launch surfaces. See `apps/macos/README.md`
and `docs/MAC_BETA_RELEASE_RUNBOOK.md` for the import and release checks.
